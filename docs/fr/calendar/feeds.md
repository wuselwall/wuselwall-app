# Partager le calendrier familial

Un **abonnement** affiche le calendrier dans une autre app, **en lecture seule**. Les modifications restent dans WuselWall. Pour importer dans l’autre sens, consultez les [calendriers externes](/fr/calendar/#outside-calendars).

Dans **Paramètres → Avancés → Partager le calendrier familial**, créez un abonnement :

1. Donnez-lui un **nom**, par exemple « Outlook au travail ».
2. Choisissez les événements et les options : **présences**, **école** (journées entières, cours individuels ou désactivée) et **calendriers externes**, désactivés par défaut. Chaque abonnement décide séparément de les inclure. Évitez les présences sur un appareil professionnel ou destiné aux enfants si elles ne sont pas nécessaires.
3. Choisissez les personnes, ou aucune pour tous les membres.
4. Créez l’abonnement.

## L’adresse {#the-address}

Elle s’affiche **une seule fois**. Toute personne qui la possède peut lire les rendez-vous : gardez-la comme un mot de passe. Chaque abonnement a sa propre clé.

Copiez l’adresse, le lien **webcal** qui ouvre l’ajout sur iPhone, ou scannez le code QR.

## S’abonner {#how-to-subscribe}

**Outlook sur le web** : Calendrier → Ajouter un calendrier → S’abonner à partir du web → coller l’adresse et nommer le calendrier.

**iPhone** : Réglages → Apps → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter un calendrier avec abonnement. Collez l’adresse, ou utilisez le lien webcal.

## Révoquer {#revoking-a-subscription}

La révocation coupe l’accès immédiatement. L’abonnement reste dans la liste comme révoqué, avec sa dernière consultation.
