## Prêt en quatre étapes

<div class="home-steps">
<div class="home-step">

<Shot name="setup-server" alt="L’écran de choix du serveur" />

[1. Installer l’app](/fr/guide/install)

Dans le navigateur, sur Android ou sur iPhone. Au premier lancement, indiquez le serveur de votre famille ou essayez la famille d’exemple.

</div>
<div class="home-step">

<Shot name="new-family" alt="Le formulaire de création d’une famille" />

[2. Créer votre famille](/fr/guide/setup#_2-creating-a-new-family)

Connectez-vous, choisissez le nom de famille et votre couleur. Vous pouvez commencer avec quelques tâches d’exemple.

</div>
<div class="home-step">

<Shot name="invite-sheet" alt="L’invitation de Mamie Ruth, son code QR et le partage" />

[3. Inviter les adultes](/fr/settings/members-devices#invite-an-adult)

Votre conjoint, les grands-parents ou la personne au pair reçoivent un lien, un code QR ou un code.

</div>
<div class="home-step">

<Shot name="pair-device" alt="Le code QR et le code du nouvel appareil" />

[4. Connecter la tablette et l’écran](/fr/guide/setup#_4-connecting-a-family-tablet-or-wall-display)

Le nouvel appareil affiche un code QR. Votre téléphone le scanne, et l’appareil fait partie de la famille.

</div>
</div>
