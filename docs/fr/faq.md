# Questions fréquentes

## Cet appareil a été bloqué

Un parent a révoqué l’accès. [Connectez à nouveau l’appareil](/fr/guide/setup#_4-connecting-a-family-tablet-or-wall-display).

## Le code est incorrect ou expiré

Les codes d’appareil durent **10 minutes** et ne servent qu’une fois. Recommencez la connexion sur le nouvel appareil pour obtenir un nouveau code. Après plusieurs erreurs, attendez quelques minutes.

## Le code d’invitation ne fonctionne pas

Une invitation dure **7 jours** et sert une fois. Demandez un nouveau partage ou une nouvelle invitation. Saisissez le code dans l’app via **J’ai un code d’invitation** ([Connexion](/fr/guide/setup#_3-joining-a-family)).

## Il faut d’abord toucher son prénom

Sur un appareil partagé, indiquez [qui vous êtes](/fr/guide/who-are-you) avant de modifier quoi que ce soit.

## Le PIN est bloqué

Après dix erreurs, définissez un nouveau PIN sur votre téléphone personnel ([Sécurité](/fr/settings/security#guardian-pin)).

## Le serveur est inaccessible

Vérifiez le Wi-Fi ou les données mobiles et réessayez. Les [courses hors ligne](/fr/shopping/store#offline) fonctionnent si la liste a déjà été chargée au moins une fois.

## Un produit apparaît deux fois

Le même nom augmente normalement la quantité à **2×**. Pour deux lignes distinctes, utilisez des noms légèrement différents.

## Où sont les tuiles ?

Elles apparaissent quand vous terminez les achats. Les premiers produits se saisissent au clavier ; la première sortie construit les premières tuiles.

## Comment changer la langue ?

Dans **Paramètres → Langue**, choisissez l’allemand, l’anglais, le français ou l’espagnol pour cet appareil ; les rappels du téléphone suivent aussi. Avec **Automatique**, l’app suit la langue de l’appareil, avec repli sur l’allemand. Le choix reste sur l’appareil, dans le navigateur pour l’app web : chaque téléphone, tablette ou navigateur de la famille peut afficher une autre langue. Le menu de langue de ce guide change seulement la documentation.
