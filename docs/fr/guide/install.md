# Installer l’app

WuselWall fonctionne dans le navigateur, sur Android et sur iPhone et iPad. Chaque installation communique avec **le serveur de votre famille** : c’est là que restent vos données.

## Premier lancement : quel serveur ? {#at-first-start-which-server}

L’app demande **Quel serveur ?**, car elle n’a pas de serveur prédéfini.

<Shot name="setup-server" alt="L’écran de choix du serveur" />

- **Saisissez l’adresse** reçue de la personne qui a installé le serveur, par exemple `api.example.org`. Pour Supabase, l’identifiant du projet suffit.
- **Scannez le code QR** d’un appareil déjà connecté, dans **Paramètres → Avancés → Serveur**. Le code d’ajout d’appareil connecte aussi l’appareil à la famille.
- **Essayez sans serveur** : une famille d’exemple fonctionne entièrement sur l’appareil. Rien n’est conservé ni envoyé. Quittez la démonstration pour revenir au choix du serveur.

L’app mémorise le serveur. Pour en changer : **Paramètres → Avancés → Serveur → Changer de serveur** ([Appareils](/fr/settings/members-devices#server)). Vous n’en avez pas encore ? Consultez [Votre propre serveur](/fr/server/).

## Dans le navigateur {#in-the-browser-on-any-device}

Ouvrez l’adresse de l’app web fournie par la personne qui gère votre serveur, sur ordinateur ou téléphone. Rien à installer.

::: tip Sur l’écran d’accueil
Sur iPhone : **Partager → Sur l’écran d’accueil**. Sur Android : **⋮ → Ajouter à l’écran d’accueil**. WuselWall s’ouvre ensuite comme une app.
:::

Les clés d’accès ne sont pas encore disponibles dans le navigateur. Utilisez le code par e-mail ou votre mot de passe.
