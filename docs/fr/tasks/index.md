# Tâches

L’espace **Tâches** comprend **Aujourd’hui**, les **approbations**, les **tâches**, les **récompenses** et les **points**.

<Shot name="tasks-today" alt="Les tâches du jour pour la famille" wide />

## Aujourd’hui {#today}

Cochez une tâche terminée ; l’annulation permet de revenir en arrière. Les tâches ouvertes à tous reviennent à la première personne qui les prend. La **série** compte les jours consécutifs, et un **joker** la préserve en cas de journée manquée, par exemple pour maladie. Sur le mur, les tâches du jour ouvrent le même tableau familial.

Sur la tablette des enfants et sur le mur, [Wusel](/fr/guide/wusel) participe : quand la dernière tâche du jour est cochée, Wusel fait la fête avec des confettis et un petit son, sur le mur en haut de la colonne de la personne. Quand un enfant demande une récompense, Wusel est fier. Pour une tâche restée en plan, Wusel ne dit rien.

## Approbations {#approvals}

Les tâches à vérifier et les demandes de récompense arrivent ici. Un parent les approuve ou les refuse.

## Créer des tâches {#creating-chores}

Dans l’onglet des tâches, créez-en une et choisissez :

- **type** : obligation, attendue de tous avec peu de points, ou bonus facultatif ;
- **points** ;
- **répétition** : une fois, chaque jour, jours ouvrables, semaine, deux semaines ou mois ;
- **période autorisée** : seulement à l’échéance ou quelques jours après ;
- **personnes** : une personne, à tour de rôle, volontaire ou tout le monde ;
- éventuelle **approbation d’un adulte**, avant attribution des points.

Une nouvelle tâche est quotidienne et revient à tour de rôle à tous les enfants (sans enfant : au volontaire) ; un titre suffit donc pour l’enregistrer.

Archiver une tâche supprime ses occurrences futures encore ouvertes. Le kit de départ propose cinq tâches, trois récompenses et quatre badges, tous modifiables.

## Récompenses {#rewards}

Chaque récompense coûte des points. Un stock vide signifie illimité. Si l’approbation est nécessaire, un parent confirme l’échange avec son PIN ; sinon, le membre peut le faire lui-même, plutôt pour de petites choses.

Une demande rejoint l’historique des récompenses en attente, échangées ou remises. Marquez la récompense une fois remise.

## Points {#points}

Le solde et les mouvements détaillent les tâches terminées ou annulées, récompenses, corrections et badges. Une correction demande toujours un motif.

## Pourquoi ce fonctionnement ? {#why-it-is-built-this-way}

Les obligations rapportent peu ; leur régularité compte davantage. Aucun classement n’oppose les enfants ; même [Notre semaine](/fr/guide/rituals#week-review) montre les tâches en un seul nombre pour toute la famille. Une petite tâche bonus doit permettre une première récompense. Les jokers évitent qu’une maladie efface une série. Ajustez ces valeurs dans les [paramètres du foyer](/fr/settings/household).
