# Compte et famille

Ces actions concernent votre compte ou tout le foyer. Elles se trouvent en bas des paramètres de **votre téléphone personnel**. La suppression du compte est toujours visible ; les autres actions sont dans la vue **Avancés**. Lisez leurs conséquences avant de confirmer.

## Mot de passe {#password}

Dans **Paramètres → Compte et sécurité → Connexion**, définissez ou changez un mot de passe d’au moins **10 caractères**. Le code par e-mail reste disponible si votre serveur envoie des e-mails ; sinon, le mot de passe est le seul accès ([E-mails](/fr/server/email)).

## Quitter la famille {#leave-the-family}

Confirmez votre départ : votre compte quitte le foyer et vos appareils sont déconnectés. Vos contributions restent dans la famille. Vous pourrez ensuite créer ou rejoindre une autre famille.

Le **dernier parent ayant un compte** ne peut pas partir : invitez d’abord un autre adulte, ou supprimez la famille.

## Supprimer la famille {#delete-the-family}

Seul un parent, sur son téléphone personnel, peut le faire, sous **Paramètres → Famille** (vue **Avancés**). Saisissez d’abord le **nom de la famille**, passez à l’étape suivante, puis saisissez **SUPPRIMER**, en majuscules, et confirmez.

**La suppression de toutes les données est immédiate et définitive**, sans délai ni restauration possible. Tous les appareils sont déconnectés. Les comptes adultes restent utilisables pour créer ou rejoindre une autre famille.

## Supprimer votre compte {#delete-your-account}

Cette action supprime votre accès et vous déconnecte partout. Votre **profil** et vos contributions restent dans la famille. Si votre connexion date de plus de cinq minutes, un code par e-mail vérifie votre identité avant de poursuivre (sans e-mails : votre mot de passe). Le dernier parent ayant un compte ne peut pas le supprimer.

Discutez ensemble avant de supprimer le foyer. Pour conserver vos données, faites d’abord un [export](/fr/settings/members-devices#export-data).
