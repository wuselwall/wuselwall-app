# Rappels

Activez les rappels sur **votre téléphone personnel**, dans **Paramètres → Rappels**. Ils sont créés sur le téléphone : **rien n’est transmis à un serveur ni à un tiers**. Ils ne sont pas proposés sur la tablette des enfants ou le mur, ni sur un appareil incompatible.

## Les rappels proposés {#what-you-get}

- **Résumé du matin** : rendez-vous, tâches et premier événement. L’heure est réglable. Pour les parents, le prochain résumé compte aussi les tâches et les demandes de récompense en attente d’approbation (« 2 approbations en attente »), telles que le téléphone les connaissait en planifiant les rappels ; ouvrir l’app met le nombre à jour.
- **Avant un rendez-vous** : pour les événements auxquels vous participez.
- **Préparation du cartable la veille** : le matériel des [cours du lendemain](/fr/school/#pack-for-tomorrow). Un parent voit tous les enfants ; un enfant sur son téléphone voit son propre matériel. Rien n’est envoyé s’il n’y a rien à préparer.

Chaque type a son interrupteur et vos réglages n’affectent que vous. Les heures proposées sont **7 h** pour le résumé et **19 h** pour le cartable ; le rappel avant rendez-vous est désactivé par défaut.

## Autorisation {#permission}

La première activation demande l’autorisation système d’afficher des notifications. Un refus empêche les rappels ; vous pouvez changer cela dans les réglages du téléphone. L’écran mural n’envoie pas de rappels : il affiche déjà les événements.
