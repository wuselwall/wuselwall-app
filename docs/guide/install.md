# App installieren

WuselWall gibt es im Browser, für Android und für iPhone und iPad. Jede Variante verbindet sich mit dem **Server eurer Familie**: Dort liegen eure Daten, nicht bei uns.

## Im Browser – auf jedem Gerät

Euer Server bringt seine eigene Web-App mit. Öffne ihre Adresse im Browser, am Laptop genauso wie am Handy. Die Adresse bekommst du von der Person, die euren Server eingerichtet hat, oder mit einer Einladung. Es gibt nichts zu installieren.

::: tip Auf dem Home-Bildschirm
Auf dem iPhone: **Teilen → Zum Home-Bildschirm**. Auf Android: **⋮ → Zum Startbildschirm hinzufügen**. Dann öffnet sich WuselWall wie eine App.
:::

Passkeys gibt es im Browser noch nicht; melde dich mit E-Mail und Passwort an.

## Android-App – Tablet und Android-Handys

Die Android-App erscheint bei **Google Play**. Bis sie dort ist, funktioniert WuselWall im Browser (siehe oben).

## iPhone und iPad

Die App für iPhone und iPad erscheint im **App Store**. Bis dahin funktioniert WuselWall im Browser (siehe oben).
