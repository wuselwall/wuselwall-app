# Einrichten

Es gibt drei Wege auf ein neues Gerät. Welcher passt, siehst du auf dem Startbildschirm:

<img class="shot" src="/screenshots/de/setup-start.png" alt="Startbildschirm eines noch nicht eingerichteten Geräts">

## 1. Neuen Haushalt einrichten (nur einmal)

Das macht die Person, die WuselWall für die Familie aufgesetzt hat – **einmal** am Anfang.

1. Tippe auf **Neuen Haushalt einrichten**.
2. Gib das **Einrichtungs-Token** ein. Das hat dir die Person gegeben, die den Server betreibt. Es gilt nur einmal.
3. Wähle einen **Haushaltsnamen** und gib deinen **Namen**, deine **E-Mail** und ein **Passwort** (mindestens 10 Zeichen) ein.
4. Lege eine **6-stellige PIN** fest. Mit ihr bestätigst du später wichtige Aktionen auf geteilten Geräten.

<img class="shot" src="/screenshots/de/setup-household.png" alt="Formular „Neuer Haushalt“">

Danach ist die Einrichtung für immer geschlossen: Niemand sonst kann einen zweiten Haushalt anlegen.

## 2. Als Erziehungsberechtigter anmelden

Auf deinem **eigenen Handy** meldest du dich mit E-Mail und Passwort an. Beim ersten Mal fragt WuselWall nach einem **Namen für das Gerät** („Handy von Lukas“) – so erkennst du es später in der Geräteliste und kannst es bei Verlust sperren.

<img class="shot" src="/screenshots/de/setup-sign-in.png" alt="Anmeldung">

Hast du die Zwei-Faktor-Anmeldung eingeschaltet, kommt danach noch der 6-stellige Code aus deiner Authenticator-App (siehe [Sicherheit](/settings/security)).

## 3. Gerät mit Code einrichten

So kommen **Kinder-Tablets**, die **Wandanzeige** und weitere geteilte Geräte in den Haushalt:

1. Ein Erziehungsberechtigter öffnet auf seinem Handy **Einstellungen → Gerät hinzufügen** und erzeugt einen Code (siehe [Mitglieder und Geräte](/settings/members-devices)).
2. Auf dem neuen Gerät tippst du auf **Dieses Gerät mit Code einrichten** und gibst den Code ein – oder scannst den QR-Code.

<img class="shot" src="/screenshots/de/setup-enrol.png" alt="Code eingeben">

Der Code gilt **10 Minuten** und nur **einmal**. Stimmt er nicht, fordere einen neuen an.
