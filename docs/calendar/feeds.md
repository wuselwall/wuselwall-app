# Den Familienkalender teilen

Ein **Abo** zeigt den Familienkalender in einer anderen App. Es ist nur zum Lesen: Termine ändert ihr weiterhin in WuselWall. Das Gegenstück, Kalender von außen in WuselWall zu holen, steht unter [Kalender von außen](/calendar/#kalender-von-aussen).

Öffne **Einstellungen → Familienkalender teilen** und tippe auf **Neues Abo**.

## Ein Abo anlegen

1. Gib dem Abo einen **Namen**, zum Beispiel „Arbeits-Laptop Outlook“.
2. Wähle unter **Was** die Termine. Außerdem:
   - **Anwesenheit** zeigt, wer wo ist (Arbeit, Homeoffice, Frei …). Für Arbeitsgeräte und Kinder lässt man das besser aus.
   - **Schule** zeigt Schultage als ganzen Tag oder jede Unterrichtsstunde. Oder aus.
   - **Kalender von außen einschließen** nimmt auch die Termine aus Kalendern von außen auf, zum Beispiel vom Verein oder der Müllabfuhr. Das ist **aus**, bis du es anhakst. Jedes Abo entscheidet also selbst, ob seine Termine mitkommen.
3. Unter **Wessen Termine** wählst du Personen. Ohne Auswahl sind alle Mitglieder dabei.
4. Tippe auf **Abo erstellen**.

## Die Adresse

Die Abo-Adresse wird **nur einmal** angezeigt. Wer sie hat, sieht die Termine. Behandle sie deshalb wie ein Passwort. Die Adresse enthält einen geheimen Schlüssel für dieses eine Abo; ein neues Abo bekommt eine neue Adresse.

Mit **Adresse kopieren** holst du die Adresse in die Zwischenablage. Mit **webcal-Link kopieren** bekommst du einen Link, der auf dem iPhone direkt den Dialog zum Abonnieren öffnet. Der QR-Code zeigt dieselbe Adresse, zum Abscannen.

## So abonnierst du

**Outlook im Web:** Kalender → Kalender hinzufügen → Aus dem Web abonnieren → Adresse einfügen → Namen „Familie“ wählen.

**iPhone:** Einstellungen → Apps → Kalender → Accounts → Account hinzufügen → Andere → Abo-Kalender hinzufügen → Adresse einfügen. Oder tippe auf den webcal-Link.

## Abo sperren

Willst du, dass ein Abo keine Termine mehr bekommt, tippe in der Liste auf **Sperren**. Das wirkt sofort. Das Abo bleibt in der Liste mit dem Hinweis **Gesperrt**. Die Liste zeigt außerdem, wann das Abo zuletzt abgerufen wurde.
