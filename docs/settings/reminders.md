# Erinnerungen

Erinnerungen bekommst du auf **deinem eigenen Handy**, wenn du sie einschaltest: unter **Einstellungen → Erinnerungen**. Sie entstehen auf dem Telefon selbst. **Nichts davon wird an einen Server oder an Dritte geschickt.** Deshalb gibt es sie nur auf dem persönlichen Gerät eines Familienmitglieds, nicht auf einem Kinder-Tablet oder der Wandanzeige.

<Shot name="reminders" alt="Einstellungen → Erinnerungen" />

## Was du bekommst

- **Morgenübersicht**: eine Benachrichtigung am Morgen, zum Beispiel „Heute: 3 Termine, 2 Aufgaben“ und „Als Erstes um 8:00: Schwimmen“. Die Uhrzeit stellst du ein. Erziehungsberechtigte sehen dort auch offene Belohnungen, die auf Freigabe warten.
- **Erinnerung vor Terminen**: eine Benachrichtigung, bevor ein Termin beginnt, zu dem du eingetragen bist.
- **Einpack-Erinnerung am Vorabend**: zum Beispiel „Für morgen einpacken – Emma: Sportsachen“, aus den [Stundenplänen](/school/#morgen-einpacken). Erwachsene bekommen sie für alle Kinder, ein Kind auf dem eigenen Handy für sich. Sie kommt nur, wenn etwas einzupacken ist.

Alles steuerst du mit einem Schalter. Die Einstellungen gelten nur für dich. Der Standard legt die Morgenübersicht auf 7:00 und die Einpack-Erinnerung auf 19:00 fest, die Terminerinnerung ist aus.

## Erlaubnis

Beim ersten Einschalten fragt das Telefon nach der Erlaubnis für Benachrichtigungen. Sagst du nein, gibt es keine Erinnerungen. Die Erlaubnis kannst du in den Systemeinstellungen deines Telefons ändern.

::: tip Auf der Wandanzeige
Die Wandanzeige hat keine eigenen Erinnerungen. Die Termine stehen dort ohnehin auf der Woche.
:::
