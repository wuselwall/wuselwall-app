# Instalar la app

WuselWall funciona en el navegador, Android, iPhone y iPad. Se conecta al **servidor de tu familia**: allí se guardan los datos.

## Primer inicio: ¿qué servidor? {#at-first-start-which-server}

La app no lleva un servidor predeterminado, por lo que pregunta **¿Qué servidor?**.

<Shot name="setup-server" alt="La elección del servidor" />

- Escribe la **dirección** recibida de quien lo instaló, por ejemplo `api.example.org`. En Supabase basta el identificador del proyecto.
- **Escanea el QR** de un dispositivo conectado, en **Ajustes → Avanzados → Servidor**. El código para añadir un dispositivo también lo conecta a la familia.
- **Prueba sin servidor**: una familia de ejemplo funciona solo en el dispositivo, sin guardar ni enviar datos. Sal de la demostración para volver a esta pregunta.

Si el servidor viene de un enlace o de un código QR escaneado, o la dirección escrita lleva a otro servidor, la app muestra primero su dirección y pregunta **¿Conectar con este servidor?** Conéctate solo a una dirección que conozcas; si tienes dudas, escríbela tú. Donde inicias sesión o escribes un código o una contraseña, la app indica en pequeño **Servidor:** y la dirección.

Si tu servidor indica más tarde una nueva dirección, la app sigue con la anterior y muestra un aviso arriba. Solo **Volver a conectar** cambia; con una nueva dirección, el dispositivo cierra la sesión y vuelves a iniciarla allí.

La app recuerda el servidor. Para cambiarlo: **Ajustes → Avanzados → Servidor → Cambiar servidor** ([Dispositivos](/es/settings/members-devices#server)). Si aún no tienes uno, consulta [Tu propio servidor](/es/server/).

## En el navegador {#in-the-browser-on-any-device}

Abre la dirección de la app web que te facilite quien gestiona el servidor. Sirve para ordenador y móvil, sin instalar nada.

::: tip En la pantalla de inicio
En iPhone: **Compartir → Añadir a pantalla de inicio**. En Android: **⋮ → Añadir a pantalla de inicio**. WuselWall se abrirá como una app.
:::

Las claves de acceso todavía no están disponibles en el navegador. Usa el código por correo o una contraseña. Si el servidor no envía correo, usa la contraseña.
