# Varias listas

Elige arriba la lista del **supermercado**, la **droguería**, la **ferretería** u otra tienda. El número junto al nombre indica los productos pendientes.

<Shot name="shopping-new-list" alt="La creación de una lista" />

## Crear una lista {#creating-a-list}

1. Toca **Nueva lista**.
2. Escribe el **nombre** y elige el tipo de tienda.
3. Guarda.

El tipo fija las **categorías** en el orden de los pasillos. Cada lista tiene **sus propias tarjetas**: la ferretería no sugiere plátanos.

## Lista predeterminada {#the-default-list}

Una estrella marca la **lista predeterminada**, inicialmente el supermercado. Es la única que usa la pantalla de pared para añadir productos. Para elegir otra, selecciónala y **mantén pulsado su nombre**.
