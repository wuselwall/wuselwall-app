# Compartir el calendario familiar

Una **suscripción** muestra el calendario en otra app, **sin poder editarlo**. Los cambios siguen en WuselWall. Para importar en sentido contrario, consulta [Calendarios externos](/es/calendar/#outside-calendars).

En **Ajustes → Avanzados → Compartir el calendario familiar**, crea una suscripción:

1. Ponle nombre, por ejemplo «Outlook del trabajo».
2. Elige eventos y opciones: presencia, colegio (días completos, clases individuales o desactivado) y calendarios externos, desactivados por defecto. Cada suscripción decide por separado si los incluye. Evita compartir presencia en equipos laborales o infantiles si no es necesaria.
3. Elige personas, o ninguna para incluir a todos.
4. Crea la suscripción.

## La dirección {#the-address}

Aparece **una sola vez**. Quien la tenga puede leer las citas: guárdala como una contraseña. Cada suscripción tiene su propia clave.

Copia la dirección, el enlace **webcal** que abre el diálogo en iPhone o escanea el QR.

## Suscribirse {#how-to-subscribe}

**Outlook web**: Calendario → Agregar calendario → Suscribirse desde la web → pegar dirección y poner nombre.

**iPhone**: Ajustes → Apps → Calendario → Cuentas → Añadir cuenta → Otra → Añadir calendario suscrito. Pega la dirección o usa el enlace webcal.

## Revocar {#revoking-a-subscription}

Revocar corta el acceso inmediatamente. La suscripción permanece en la lista como revocada, con la fecha de su última consulta.
