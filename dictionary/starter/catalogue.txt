# WuselWall starter catalogue (issue #197, dictionary/README.md "Starter catalogue").
#
# The most common items of each shopping-list kind, so that a new family's list has tiles and
# search suggestions before anything was bought. Rendered by scripts/starter.mjs into
# app/assets/matching/starter.json, with the picture of each name looked up in the shopping
# dictionary (shopping.txt) by the same rule as the server: the whole name, then its last word,
# then the longest known word the last word ends with.
#
# Format
#   [kind]            a list kind: supermarket | drugstore | hardware
#   produce:          a category key, as app.shopping_seed_categories seeds it; the sections of a
#                     kind come in walking order (supermarket: produce, bakery, dairy, meat_fish,
#                     pantry, snacks, frozen, drinks, household, other)
#     de: A, B, C     a tag and comma-separated names in natural spelling, most common first.
#                     de and en are required in every section; fr and es are optional.
#     de-CH: A = B, + C
#     de-AT: A = B    overrides of the de list, never a full list. `base = regional` replaces the
#                     base name by the regional one at the same place; `+ Name` appends a name.
#                     The rendered de-CH and de-AT lists are full lists.
#
# A name may appear once per kind and tag. Plural where people buy plural (Bananen, Äpfel),
# singular for bulk (Milch, Brot, Mehl). Everyday things a family really buys.
# Run: node scripts/starter.mjs build | check | stats
